# 🔒 jwt-session-revoker

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Store: Redis](https://img.shields.io/badge/Cache-Redis%20TTL-red.svg)](https://redis.io)

Distributed JWT token revocation and immediate session termination engine. Eliminates the traditional security drawback of stateless JWTs during credential compromise or user logout.
